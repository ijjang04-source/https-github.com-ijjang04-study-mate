# 공부 메이트 — 학생용 한 장 안내

1. **입장**: 주소를 열고 학교·학년·반, 선생님께 받은 입장 코드, 출석번호, 닉네임(실명 말고!)을 넣어. 기록은 이 기기에만 저장되니 시크릿 창은 쓰지 마.
2. **진단**: '진단' 탭에서 10분쯤 답하면 나의 공부 스타일이 스펙트럼으로 나와. 중간에 멈춰도 '이어서 하기'로 계속할 수 있어. 결과는 지워지지 않고, 진단 옆 '결과' 탭이나 전략 화면 맨 위에서 마지막 결과를 언제든 다시 볼 수 있어. 4주쯤 뒤에 다시 하면 '결과 기록' 탭에서 지난 결과와 비교해 볼 수 있어.
3. **전략**: '전략' 탭에서 과목마다 추천 전략 3개 중 하나를 골라 '이 전략으로 할래'를 눌러. 고른 전략이 플래너에 들어가. 그다음 '나만의 한 가지 전략'으로 "나는 [언제] [무엇을] 한다" 한 문장을 만들어 봐.
4. **플래너**: 월간(목표·시험) → 주간(전략 배치) → 일간(오늘 블록)을 채우고, 공부한 뒤 블록마다 '기록하기'를 눌러. 일간 맨 위에서 오늘 나만의 한 가지 전략을 지켰는지도 체크해.
5. **점검**: 일요일에 '점검' 탭의 주간 점검표를 쓰면 '다음 주에 바꿀 한 가지'가 다음 주 플래너로 넘어가. 공용 기기라면 다 쓰고 꼭 '나가기'를 누르고, 한 달에 한 번 설정에서 백업해!
