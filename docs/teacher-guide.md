# 공부 메이트 — 선생님용 안내서

공부 메이트는 학생이 **진단 → 전략 → 플래너 → 점검**을 스스로 돌리도록 돕는 웹 앱입니다.
서버가 없고, 학생 기록은 **학생이 쓰는 기기의 브라우저에만** 저장됩니다. 선생님도 학생 기록을 볼 수 없습니다.

---

## 1. 입장 코드 만들기 (`#/teacher`)

반마다 **공용 입장 코드 하나**(숫자 4~6자리)를 정합니다. 학생 개인 번호가 아닙니다.

1. 먼저 `js/config.js`의 `schools`에 학교가 있는지 확인합니다. 없으면 2장 ①처럼 먼저 넣고 저장합니다.
   (`#/teacher` 화면의 학교 목록은 `schools`에서 가져옵니다.)
2. 앱 주소 뒤에 `#/teacher`를 붙여 엽니다. 예: `https://아이디.github.io/study-mate/#/teacher`
   입장 화면 아래의 **"선생님이신가요?"** 링크를 눌러도 됩니다.
3. 학교·학년·반을 고르고 정한 **입장 코드**를 입력한 뒤 **해시 만들기**를 누릅니다.
4. **"두 해시 모두 (권장: 어떤 기기에서든 입장 가능)"** 줄 옆의 **복사**를 누릅니다.

- 이 화면은 코드를 저장하지 않습니다. 코드 원문은 선생님만 기억해 두세요.
- https 주소에서 열어야 SHA-256 해시도 함께 만들어집니다. `file://`로 연 화면에서는 대체 해시만 나오며, 대체 해시만 넣어도 입장은 됩니다.
- **코드 고르기**: `1234`, `0000`, 생일·학번 같은 짐작하기 쉬운 숫자는 피합니다. 반마다 다르게 정합니다.
- **한계**: 숫자 코드는 자리 수가 적어 `config.js`(공개 파일)를 본 사람은 알아낼 수 있습니다. 다른 반 학생이 실수로 들어오지 않게 하는 정도의 잠금으로 생각하고, 반 밖으로 퍼지면 새 코드로 바꿉니다.

## 2. `config.js`에 붙여 넣기

`js/config.js`를 메모장이나 GitHub 웹 편집기(파일 열기 → 연필 아이콘)로 엽니다.

① **학교** — `schools` 목록에 한 줄을 넣습니다. 학교코드는 영문·숫자만 씁니다.

```js
schools: [
  { id: 'SM01', name: '숙명고등학교' }
],
```

② **반** — 1장에서 복사한 줄을 `classes` 목록 안에 붙여 넣습니다. 반마다 한 줄입니다.

```js
classes: [
  { school: 'SM01', grade: 2, cls: 3, codeHash: ['(SHA-256 해시)', 'fb:(대체 해시)'] },
  { school: 'SM01', grade: 2, cls: 4, codeHash: ['(SHA-256 해시)', 'fb:(대체 해시)'] },
],
```

③ **체험용 DEMO 지우기** — `schools`의 `DEMO` 줄과 `classes`의 `// DEMO 1학년 1반` 블록을 지웁니다. 남기면 누구나 체험 코드로 입장할 수 있습니다.

④ 저장(커밋)하면 1~2분 뒤 배포 주소에 반영됩니다. 학생 입장 화면에서 학교·반이 보이는지, 코드로 입장되는지 직접 확인합니다.

주의:
- 따옴표(`'`)와 쉼표(`,`)를 지우지 않습니다. 문법이 틀리면 앱 전체가 열리지 않습니다. 수정 뒤 앱이 하얗게 나오면 마지막 수정을 되돌립니다.
- 코드를 바꾸려면 1장에서 새 해시를 만들어 그 반 줄의 `codeHash`만 바꿉니다. **이미 입장해 있던 학생의 기록은 그대로** 남고, 다음 입장부터 새 코드가 필요합니다.
- `bannedWords`(닉네임·댓글 금칙어), `subjects`(과목), `autoLogoutMinutes`(자동 로그아웃 기본 시간), `crisis`(위기 대응 안내 문구와 연락처)도 학교 사정에 맞게 고칠 수 있습니다.

## 3. 학생에게 안내할 문구 (예시)

> 📚 **공부 메이트 시작하기**
> 1. 주소: https://아이디.github.io/study-mate/ (휴대폰 홈 화면에 추가해 두면 편해요)
> 2. 학교 ○○고, ○학년 ○반, 입장 코드 **(칠판에만 적기)**, 내 출석번호, 닉네임을 넣고 입장
> 3. 닉네임은 친구들에게 보여요. **실명·전화번호는 쓰지 마세요.**
> 4. 기록은 **내 휴대폰(내 브라우저)에만** 저장돼요. 시크릿 창에서는 창을 닫으면 사라져요.
> 5. 진단 → 추천 전략 → 플래너 → 일요일 점검 순서로 해 보세요. 자세한 건 학생용 안내를 보세요.

- 입장 코드는 단체 채팅방·게시판처럼 남는 곳보다 칠판·구두로 알려 주는 편이 안전합니다.
- 학생용 한 장 안내: [student-guide.md](student-guide.md)

## 4. 공용 기기(교실 태블릿·컴퓨터실)에서 쓸 때

- **다 쓰면 반드시 오른쪽 위 '나가기'**를 누르게 합니다. 나가지 않으면 다음 학생이 앞 학생 기록을 볼 수 있습니다.
- **자동 로그아웃**: 아무것도 안 하면 정해진 시간 뒤 자동으로 나갑니다. 기본 30분이며, 설정(오른쪽 위 '설정' → 보안)에서 15/30/60분으로 바꿀 수 있습니다. 이 값은 **그 기기 전체**에 적용됩니다. 공용 기기는 15분 또는 30분을 권합니다.
- 같은 기기를 여러 학생이 쓰면 기록이 모두 그 기기에 쌓입니다. 한 학생의 1년치가 약 2.7 MB이고 브라우저 저장 공간은 약 5 MB라, **한 기기를 오래 함께 쓰기는 어렵습니다.** 되도록 학생 개인 기기를 쓰게 하고, 공용 기기라면 학기마다 백업 후 정리합니다(설정 → 저장 공간에서 사용량 확인, 4 MB가 넘으면 경고).
- **'우리 반' 피드**는 반 서버가 없으면 **같은 기기에서 입장한 친구들의 계획만** 보입니다. 반 전체가 서로의 계획을 보려면 반 서버(구글 시트)를 켭니다: [remote-setup.md](remote-setup.md)
- 브라우저의 "인터넷 사용 기록 삭제(쿠키 및 사이트 데이터)"를 하면 그 기기의 모든 학생 기록이 지워집니다. 기기 관리 담당자에게 미리 알립니다.

## 5. 백업 안내

기록이 기기에만 있으므로, 아래 경우 전에는 **백업**을 안내합니다.
휴대폰 교체·초기화, 브라우저 데이터 삭제, 공용 기기 정리, 학기·학년 말.

**백업하기**: 오른쪽 위 **설정 → 백업 → 내 데이터 내보내기**를 누릅니다. `study-mate-닉네임-날짜.json` 파일이 내려받아집니다.
- 설정 화면에 마지막 백업 날짜가 보이고, 30일이 넘으면 "백업한 지 오래됐어요"가 뜹니다.
- 파일에는 그 학생의 진단·전략·플래너·점검·대화와, 우리 반 피드에 올린 **자기** 계획·댓글만 들어갑니다. 친구 댓글은 들어가지 않습니다.

**되돌리기**: 새 기기에서 **같은 학교·반·번호**로 입장합니다. 그다음 설정 → 백업 → 파일 선택으로 백업 파일을 고르고, 방법을 정한 뒤 불러오기를 누릅니다.
- **없는 것만 추가**: 지금 기록은 두고 빠진 것만 채웁니다. 보통 이쪽을 씁니다.
- **덮어쓰기**: 같은 항목을 백업 내용으로 바꿉니다.

다른 학생의 백업 파일은 불러올 수 없습니다.

**전체 삭제**: 설정 맨 아래 **내 데이터 전체 삭제**입니다. 확인을 두 번 받으며, 두 번째에는 닉네임을 직접 입력해야 합니다. 그 학생 기록과 피드의 자기 글만 지워지고, 같은 기기의 다른 학생 기록은 그대로입니다.

## 6. 자주 묻는 질문

- **학생이 입장 코드를 틀렸다고 나와요.** 학교·학년·반이 맞는지 먼저 확인합니다. 5번 연속 틀리면 60초 동안 잠깁니다.
- **같은 번호에 다른 닉네임으로 들어오려 해요.** "이미 ○○(으)로 등록된 번호예요. 본인이 맞나요?" 확인 창이 뜨고, '네, 본인이에요'를 누르면 원래 기록으로 들어갑니다. 닉네임은 설정에서 바꿀 수 있습니다.
- **챗봇에 위험한 말을 쓰면요?** 자해·자살 관련 표현이 보이면 챗봇은 다른 대답보다 먼저 담임·상담 선생님께 이야기하라고 하고, 청소년 상담 1388, 자살예방 상담 109를 안내합니다. 이 내용은 학생 기기에만 있어 선생님께 자동으로 알려지지 **않습니다**. 학생에게 이 점을 미리 말해 두고, 평소 상담 창구를 함께 안내해 주세요. 문구는 `config.js`의 `crisis`에서 바꿀 수 있습니다.
- **선생님이 학생 기록을 모아 볼 수 있나요?** 지금 버전은 안 됩니다. 학생이 월간 리포트를 인쇄하거나(점검 → 월간 리포트 → 인쇄하기) 백업 파일을 직접 보여 주는 방식만 됩니다.
