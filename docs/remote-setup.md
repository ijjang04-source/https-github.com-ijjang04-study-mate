# 반 서버 설정하기 (Google Apps Script + 구글 시트)

반 서버를 켜면 **우리 반 피드**(공개한 주간 계획 요약·댓글·반응)가 학생마다 다른 기기에서도 함께 보입니다.
플래너·점검표·진단 결과·대화는 지금처럼 **학생 기기에만** 있고 서버로 가지 않습니다.

반 서버를 켜지 않으면(`config.js`의 `remote: null`) 앱은 지금과 똑같이 동작합니다.

- 필요한 것: 학교 Google 계정(시트를 만들 수 있는 계정), 이 앱을 배포한 GitHub 저장소
- 걸리는 시간: 약 15분
- 비용: 없음

---

## 1. 시트와 스크립트 만들기

1. 학교 계정으로 Google 드라이브에서 **새 스프레드시트**를 만듭니다. 이름 예: `공부 메이트 반 서버`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 내용을 모두 지우고, 저장소의 [`server/apps-script.gs`](../server/apps-script.gs) 내용을 **전부** 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 목록에서 **`setup`**을 고르고 **실행**을 누릅니다. 처음에는 권한을 묻습니다. 내 계정을 고르고 허용합니다.
   ("Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 선생님이 직접 만든 스크립트라서 나오는 안내입니다.)
5. 시트로 돌아가면 `classes`, `items` 탭이 생겨 있습니다.

## 2. 반과 입장 코드 적기

`classes` 탭에 반마다 한 줄씩 적습니다.

| 반ID (예: SM01-2-3) | 입장 코드 |
|---|---|
| SM01-2-3 | 4821 |
| SM01-2-4 | 7305 |

- 반ID는 `학교코드-학년-반`입니다. `config.js`의 학교코드와 같아야 합니다.
- 입장 코드는 **`config.js`에 해시로 넣은 코드와 같은 숫자**여야 합니다(아래 주의 참고).
- B열은 `setup`이 '일반 텍스트' 서식으로 바꿔 둡니다. `0123`처럼 0으로 시작해도 그대로 적힙니다.
- 이 시트는 선생님만 보도록 **공유하지 않습니다.**

## 3. 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택(⚙) → **웹 앱**을 고릅니다.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 고르고 **배포**를 누릅니다.
   - '모든 사용자'여야 학생들이 로그인 없이 쓸 수 있습니다. 반 키가 맞지 않으면 서버가 거절합니다.
   - 학교 관리자가 외부 공개를 막아 두었으면 '모든 사용자'가 보이지 않습니다. 이때는 관리자에게 문의합니다.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 브라우저 새 탭에 그 주소를 열어 "공부 메이트 반 서버가 동작 중이에요."가 보이는지 확인합니다.

## 4. 앱에 연결하기

`js/config.js`에서 `remote: null`을 아래처럼 바꾸고 커밋(push)합니다.

```js
remote: { type: 'apps-script', url: 'https://script.google.com/macros/s/(복사한 주소)/exec' },
```

1~2분 뒤 배포 주소에 반영됩니다.

## 5. 확인하기

1. 학생 휴대폰 두 대(또는 일반 창 + 다른 브라우저)로 같은 반에 입장합니다.
2. 한쪽에서 플래너 → 주간 → **반에 공개**를 켜고, 다른 쪽에서 **우리 반** 탭을 엽니다. 30초 안에 계획이 보이면 성공입니다.
3. `items` 탭에 줄이 생긴 것도 확인합니다.

이전에 한 기기를 함께 쓰며 피드를 쓰던 반이라면, 학생마다 **설정 → 반 서버 → 우리 반 기록을 반 서버로 올리기**를 한 번 누르게 합니다. 자기 계획·댓글·반응만 올라가고, 여러 번 눌러도 겹치지 않습니다.

---

## 알아 둘 것

**입장 코드는 두 곳에 있습니다(이번 버전).**
- 입장할 때는 `config.js`의 해시로 확인합니다.
- 반 서버는 `classes` 시트의 코드로 확인합니다.
- 두 코드가 다르면, 입장은 되지만 피드에 쓴 것이 "보내지 못했어: 반 키가 맞지 않아"로 되돌아갑니다.
- 코드를 바꿀 때는 **두 곳을 함께** 바꿉니다. 시트 변경은 10분 안에 반영됩니다.
- 학생은 코드가 바뀐 뒤 한 번 **나가기 → 다시 입장**해야 새 반 키를 받습니다.
- 다음 단계에서 입장 확인을 서버로 옮기면 시트 한 곳만 관리하면 됩니다.

**서버가 막는 것과 못 막는 것**
- 막는 것:
  - 반 키가 틀린 요청(10분에 30번 넘게 틀리면 잠시 막음)
  - 다른 반 항목
  - 200자 넘는 댓글
  - 정해진 칸 밖의 내용(일간 기록·점검표·진단 결과 같은 것은 받지 않음)
- 아직 못 막는 것: 같은 반 학생이 다른 번호인 척 쓰는 것
  - 출석번호는 본인 확인이 안 되기 때문입니다. 지금 앱(같은 기기)과 같은 수준입니다.
  - 다음 단계(서버 입장 확인과 서명 토큰)에서 막습니다.
  - 문제가 생기면 `items` 탭에서 그 줄을 지우면 됩니다.

**개인정보**
- 시트에는 출석번호가 들어간 학생 ID(`SM01-2-3-15`), 닉네임, 공개한 주간 목표·전략, 댓글이 저장됩니다. 실명·연락처는 없습니다.
- 데이터는 선생님 학교 계정의 드라이브에 있고, 학교 Google Workspace 정책을 따릅니다.
- 학년이 끝나면 시트를 내려받아 보관하거나 삭제합니다.
- 삭제나 비공개 전환은 바로 지우지 않고 '삭제 표시'를 남깁니다(다른 기기가 지워진 걸 알도록). 편집기에서 **`cleanup`**을 실행하면 30일 지난 삭제 표시가 정리됩니다.

**스크립트를 고친 뒤에는**
- **배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포**로 다시 배포합니다.
- 이렇게 하면 URL이 그대로라 `config.js`를 바꿀 필요가 없습니다. '새 배포'를 누르면 URL이 바뀝니다.

**제한**
- Apps Script는 동시에 약 30개 요청까지 처리합니다.
- 앱은 '우리 반' 화면이 열려 있을 때만 30초마다 확인하므로 한 학년(10반 안팎)까지는 괜찮습니다.
- 응답에는 0.5~2초가 걸립니다. 다른 기기의 댓글은 최대 30초 늦게 보입니다.
- `file://`로 연 앱은 반 서버를 쓰지 않습니다(브라우저가 SHA-256을 막음). 배포한 https 주소로 엽니다.

**문제가 생기면**

| 증상 | 확인할 것 |
|---|---|
| 친구 계획이 안 보임 | 웹 앱 URL을 새 탭에서 열었을 때 동작 메시지가 나오는지, `config.js`의 주소 끝이 `/exec`인지 |
| "반 키가 맞지 않아" | `classes` 시트의 반ID·코드가 `config.js`와 같은지, 학생이 코드가 바뀐 뒤 다시 입장했는지 |
| "반 서버에 등록되지 않은 반이야" | `classes` 시트에 그 반 줄이 있는지(반ID 오타) |
| "시트가 없어요" | 편집기에서 `setup`을 실행했는지 |
| 계속 '보내는 중' | 학생 기기가 인터넷에 연결돼 있는지. 연결되면 자동으로 보냅니다(설정 → 반 서버에서 남은 개수 확인) |
